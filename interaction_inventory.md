# Finella Interaction Inventory

The following interaction map turns the product requirements into prototype-visible outcomes. Buttons that create or modify mock data may also show a brief confirmation, but no visible control is intentionally inert.

| Surface | Control | Resulting state or destination |
|---|---|---|
| Home | FinScore card | FinScore overview and category-detail drilldown |
| Home | Profile / settings / notifications | Profile, settings, and grouped notification inbox |
| Home | R-Streak card / reconcile prompt | R-Streak calendar or daily reconciliation workflow |
| Home | Asset and activity rows | Asset manager or transaction detail/list |
| Transactions | Date, sort, filter, categorised tabs | An applied local selection, menu, or filtered list |
| Transactions | Transaction row | Detail sheet with edit, categorise, and delete flows |
| Transactions | Add action | Add transaction form; expense, income, and transfer variants |
| Budgets | Category/Tag tabs, budget card, add action | Tab switch, budget detail, add/edit budget sheet |
| Insights | Insight / budget / goal cards | Insight detail, budget detail, or goal detail |
| R-Streak | Date, account, resolve option | Date reconciliation, account verification, or mismatch-resolution outcome |
| Fin AI | Suggested prompt / composer | User message followed by contextual Fin response |
| Notifications | Notification row / source action | Read state and related screen or action detail |
| More | All quick actions and management cards | Relevant report, budget, categories, tag, goal, security, help, feedback, or about screen |
| Settings | Profile, account, data/sync, finance, app, and support rows | Destination screen, toggle, select sheet, or confirmation form |
| Global | Floating add action | Add Transaction, Income, Transfer, or Budget action sheet |
